# Adaptador Vercel

Esta pasta receberá o adaptador que exporta a aplicação Express do backend para a Vercel. As rotas públicas continuarão sendo `/saude` e `/perguntar`, na mesma origem do frontend.

O adaptador será implementado e verificado junto com a configuração de publicação na etapa 5. A lógica da API ficará no backend para ser a mesma em desenvolvimento, testes e produção.
