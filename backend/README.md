# Backend

Workspace reservado à API Node.js com Express e ao serviço Gemini.

A etapa 2 implementará `GET /saude`, `POST /perguntar`, validação e tratamento de erros. A função de criação da aplicação permitirá injetar um serviço de IA simulado nos testes, sem abrir porta ou chamar serviços externos.

Somente este lado da aplicação terá acesso a `GEMINI_API_KEY`. Não registrar chaves, textos de estudo ou respostas em logs. Dependências e comandos de execução serão adicionados com a implementação.
