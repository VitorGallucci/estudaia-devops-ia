# Frontend

Workspace reservado à interface em HTML, CSS e JavaScript com Vite.

A etapa 3 implementará os campos de texto e pergunta, envio à API, resposta, carregamento, erros, cópia e limpeza. O frontend nunca acessará o Gemini diretamente e não terá chaves de API.

Dependências e comandos de desenvolvimento/build serão adicionados junto com a interface. Não existe página funcional nesta etapa.
